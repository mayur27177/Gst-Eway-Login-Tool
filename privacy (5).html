Main functions

  • Import supported bank statement transaction records
  • Import supported sales invoice data
  • Import supported purchase invoice data
  • Review ledger, item and tax mappings
  • Post selected vouchers to the active Tally company
  • Track processing and posting status locally

Controlled Tally posting

Important: The user must review the selected company, period, mappings and voucher/report details before relying on the output.

The application does not connect to a bank account or initiate bank payments. It processes only the files selected by the user and communicates with the locally accessible Tally instance for user-requested accounting functions.

How it works

A guided workflow using authorised local business data.

Select the data type
Choose Bank, Sales or Purchase and open the supported local file.
Connect to Tally
Keep the correct Tally company open and verify the company and period.
Map and review
Review ledgers, items, taxes, voucher types and transaction details.
Post selected vouchers
Send only reviewed records to Tally and verify the resulting vouchers.
